# Go file names

Go file names are the feature squashed into one word (`tripstories.go`, `placeareas.go`, `albumsuggest.go`), with an underscore only before a part of that feature (`triplines_route.go`, `bulktags_answer.go`, `routes_<area>.go`). Tests add `_test`.
