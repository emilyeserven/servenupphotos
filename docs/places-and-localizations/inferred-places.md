# Inferred places

An old free-text place name (`placeName`) written on two or more photos, ignoring case, that isn't a place's name or ID yet is an **inferred place**. The Places page lists them under the table, each with **Save as a place**, and the Photo page's place combobox offers them after the saved places ("Inferred from 3 photos") while it lists every place. Choosing one saves it as a place (its ID made from its name, as for any new place) and then chooses it. Nothing is saved until one is chosen.

> **Frontend analogy:** like a tag input that suggests tags other posts already use, before they're in the tag list.
