# Groups: Album, Tag and Genre

A **Groups** button opens one picker for the album, tag and genre filters (`components/group-picker.tsx`), like [When](when.md): a list of **Albums**, **Tags** and **Genres** on the left, each saying what it's set to (or "Any") with a dot while it's set, and the chosen one's choices on the right, each with how many photos it would show given the other filters. One of each can be chosen at once, and the button's badge says how many are. Clicking the chosen choice again, or the "All …" row at the top, clears it. Above each list, a search box narrows it to the choices whose names have the text (`lib/group-list.ts`): a match shows with everything under it, and a parent that doesn't match stays, dimmed, above a match under it so you can see where it sits. Beside it, a **Sort** menu (`components/group-list-controls.tsx`) orders the list A to Z, Z to A, by most photos or by fewest photos; Albums and Genres also have, and start on, **Set order**, and Tags start on A to Z. Each sub-album, child tag or subgenre is sorted among the others under the same parent, so it stays under it. The search and sort start over when you switch section or reopen the picker. On phones the left list folds up above the choices, under a button naming the section shown, and the picker keeps 16px from the screen's edges.

**Albums** lists every album in `ALLALBUMS.json`, each sub-album under its parent. Choosing an album (`?album=<id>`) shows the photos in it and in any album inside it. **Tags** lists every tag in `ALLTAGS.json` (`?tag=<id>`), each [under its parent tag](../albums-and-tags.md#parent-tags); choosing one shows the photos with it or any tag under it, and is left out while there are no tags. **Genres** lists every [photographic genre](../photographic-genres.md) in `ALLGENRES.json`, in the order set on [Reorganize Genres](../photographic-genres.md#reorganize-genres) and each [subgenre](../photographic-genres.md#subgenres) under its genre (`?genre=<id>`); choosing one shows the photos with it or any subgenre under it, and is likewise left out while there are none. **Likes** shows only in the pipeline's [Gallery](../gallery.md#likes-in-the-groups-picker), where each photo says whose [Like lists](../viewer-likes.md) it's in; the portfolio doesn't read the lists, so it never has the section.
